## Reproducibilidad y Ejecución

Para ejecutar este proyecto de forma reproducible:

1.  **Entorno Virtual:** Activa tu entorno virtual e instala las dependencias congeladas:
    ```bash
    pip install -r requirements.txt
    ```
2.  **Ejecución del Script:** Para correr el modelo con los valores por defecto (baseline):
    ```bash
    export PYTHONPATH=.
    python src/train.py
    ```
3.  **Parametrización:** Puedes modificar los hiperparámetros desde la línea de comandos:
    ```bash
    python src/train.py --c 0.1 --solver saga --penalty l1 --seed 42
    ```
4.  **Control de la Semilla:** El parámetro `--seed` (por defecto 42) fija el estado aleatorio tanto en la partición de datos (`train_test_split`) como en la inicialización de `LogisticRegression`, garantizando que ejecuciones con los mismos parámetros generen resultados idénticos.
